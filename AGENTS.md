# Project instructions

## Superpowers

At the start of every task in this repository, load and follow Superpowers'
`using-superpowers` skill. Use it to select and follow the Superpowers
workflows that apply to the task.

When the skill is absent from the session's skill list, read
`skills/using-superpowers/SKILL.md` from the newest installed Superpowers
version under `~/.codex/plugins/cache/*/superpowers/`. Resolve the other
Superpowers skills from that same installation.
