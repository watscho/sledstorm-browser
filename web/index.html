System requirements

Player

Desktop browser with WebAssembly SIMD and WebGL 2. Enable graphics acceleration.

For a first test: a modern 4-core CPU and 8 GB RAM. Start with the default Clean filter.

Dedicated host

Chrome, Python, Node.js and PAL game files. Internet play also needs cloudflared and a stable upload connection.

For hosting and playing on one machine: aim for a modern 6-core CPU, 16 GB RAM and 5 GB free for setup.

Hardware figures are starting points for one room; minimums have not been benchmarked.
